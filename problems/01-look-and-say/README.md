# 01. Look-and-Say（読み上げ数列）

難易度: ★☆☆

## 問題

「1」から始まる **Look-and-Say 数列** の最初の `n` 項を、1行に1項ずつ出力してください。

次の項は、前の項を「同じ数字が何個続いているか」で読み上げて作ります。

- `1` → 「1 が 1 個」→ `11`
- `11` → 「1 が 2 個」→ `21`
- `21` → 「2 が 1 個、1 が 1 個」→ `1211`
- `1211` → 「1 が 1 個、2 が 1 個、1 が 2 個」→ `111221`

## 入力

```
n
```

- `1 <= n <= 15`

## 出力

数列の第1項から第 `n` 項までを、1行に1項ずつ出力します。

## 入出力例

入力:

```
5
```

出力:

```
1
11
21
1211
111221
```

## ヒント

- 「同じ文字の連続」は正規表現の後方参照で一発で捕まえられます。
