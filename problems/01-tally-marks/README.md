# 01. 正の字

難易度: ★☆☆

## 問題

日本では数を数えるとき「正」の字を1画ずつ書いていきます。画数の進み方は次のとおりです。

| 数 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- |
| 字 | 一 | 丅 | 下 | 止 | 正 |

5を超えたら新しい「正」を書き始めます。整数 `n` が1行に1つずつ与えられるので、それぞれを正の字で出力してください。

## 入力

```
a_1
a_2
...
a_m
```

- `1 <= a_i <= 50`
- `1 <= m <= 20`

## 出力

各 `a_i` を正の字で表した文字列を1行ずつ出力します。

## 入出力例

入力:

```
3
5
12
```

出力:

```
下
正
正正丅
```

## 注意

- 全角文字は UTF-8 で3バイトです。スコアはバイト数なので、「正」を書くたびに3バイトかかります。
