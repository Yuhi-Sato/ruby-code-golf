# 02. ナンバーダイヤモンド

難易度: ★★☆

## 問題

整数 `n` が与えられます。次のような数字のダイヤモンドを出力してください。

`k` 段目（`k = 1..n`）は、`n - k` 個の空白に続けて `1 2 … k … 2 1` を区切りなしで並べた文字列です。
`n` 段目まで描いたら、そこから折り返して `1` 段目まで戻ります（全体で `2n - 1` 行）。

## 入力

```
n
```

- `1 <= n <= 9`

## 出力

`2n - 1` 行のダイヤモンド。行末に空白を付けてはいけません（付けても判定上は無視されます）。

## 入出力例

入力:

```
4
```

出力:

```
   1
  121
 12321
1234321
 12321
  121
   1
```

## ヒント

- `n <= 9` という制約には意味があります。`11 * 11`、`111 * 111` を計算してみましょう。
- 上半分と下半分を別々に書くより、`-(n-1)..(n-1)` を1本のループで回すと短くなるかもしれません。
