# 02. 定規

難易度: ★☆☆

## 問題

長さ `n` の定規を2行のテキストで描いてください。

1行目は目盛りです。位置 `i`（`0 <= i <= n`）の文字は次のとおりです。

- `i` が10の倍数なら `|`
- そうでなく5の倍数なら `:`
- それ以外は `.`

2行目は数字です。10の倍数の位置 `i` に、`i` を10進数で左詰めに書きます（`10` なら位置10に `1`、位置11に `0`）。それ以外の位置は空白です。

## 入力

```
n
```

- `1 <= n <= 60`

## 出力

2行の定規。行末の空白は判定上無視されます。

## 入出力例

入力:

```
23
```

出力:

```
|....:....|....:....|...
0         10        20
```
