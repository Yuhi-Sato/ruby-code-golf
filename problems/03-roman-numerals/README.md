# 03. ローマ数字

難易度: ★★★

## 問題

複数行にわたって整数が与えられます。それぞれをローマ数字に変換して、1行ずつ出力してください。

| 記号 | 値 |
| --- | --- |
| `I` | 1 |
| `V` | 5 |
| `X` | 10 |
| `L` | 50 |
| `C` | 100 |
| `D` | 500 |
| `M` | 1000 |

4 と 9 の位は減算表記を使います（`IV` = 4, `IX` = 9, `XL` = 40, `XC` = 90, `CD` = 400, `CM` = 900）。
同じ記号を4つ以上並べてはいけません（`IIII` ではなく `IV`）。

## 入力

```
a_1
a_2
...
a_m
```

- `1 <= a_i <= 3999`
- `1 <= m <= 100`

## 出力

各 `a_i` のローマ数字表記を、入力と同じ順に1行ずつ出力します。

## 入出力例

入力:

```
4
9
14
1994
3999
```

出力:

```
IV
IX
XIV
MCMXCIV
MMMCMXCIX
```

## ヒント

- 位取りの表を持って `divmod` していく素直な方法のほかに、
  `"I" * n` から始めて文字列置換だけで組み立てるという変わった方法もあります。
- `$<` を使うと複数行の入力をまとめて扱えます。
