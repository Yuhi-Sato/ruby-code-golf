# 03. バージョンソート

難易度: ★☆☆

## 問題

`3.3.10` のようなバージョン番号が1行に1つずつ与えられます。これらを古い順（昇順）に並べ替えて出力してください。

バージョンは `.` で区切られた整数の列で、先頭の数から順に数値として比較します。
片方が先に尽きた場合は、足りない部分を `0` とみなします（ただし、そのせいで等しくなる組は入力に含まれません）。

- `3.3.9 < 3.3.10`（文字列ではなく数値として比較）
- `3.4 < 3.10.0`
- `0.9.99 < 0.9.100 < 0.10`

## 入力

```
v_1
v_2
...
v_m
```

- 各 `v_i` は1〜4個の整数（0以上999以下）を `.` でつないだもの
- `1 <= m <= 30`
- 比較して等しくなるバージョンの組は含まれません

## 出力

並べ替えたバージョンを1行ずつ出力します。

## 入出力例

入力:

```
3.3.10
3.3.9
3.10.0
3.4
2.7.8
```

出力:

```
2.7.8
3.3.9
3.3.10
3.4
3.10.0
```
