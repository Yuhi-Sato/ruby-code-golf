# 04. 和暦

難易度: ★★☆

## 問題

西暦の日付が `YYYY-MM-DD` の形式で1行に1つずつ与えられます。それぞれを和暦に変換して出力してください。

元号と、その元年の初日は次のとおりです。

| 元号 | 初日 |
| --- | --- |
| 大正 | 1912-07-30 |
| 昭和 | 1926-12-25 |
| 平成 | 1989-01-08 |
| 令和 | 2019-05-01 |

年は「西暦年 − 元年の西暦年 + 1」で、1年は `元年` と書きます。月と日は先頭に0を付けません。

## 入力

```
d_1
d_2
...
d_m
```

- 各 `d_i` は 1912-07-30 から 2099-12-31 までの実在する日付
- `1 <= m <= 30`

## 出力

`<元号><年>年<月>月<日>日` の形で1行ずつ出力します。

## 入出力例

入力:

```
2026-11-20
2019-05-01
1989-01-07
```

出力:

```
令和8年11月20日
令和元年5月1日
昭和64年1月7日
```

## ヒント

- 日付ライブラリを使わなくても、`YYYYMMDD` を1つの整数として比べれば前後関係はわかります。
