# 05. しりとり審判

難易度: ★★☆

## 問題

ローマ字で書かれたしりとりの記録が1行に1語ずつ与えられます。最初に反則した語が何語目かを出力してください。反則がなければ `0` を出力します。

1語目から順に、次のどれかに当てはまる語を反則とします。

1. 2語目以降で、語の最初の文字が直前の語の最後の文字と違う
2. それより前に同じ語が出ている
3. 語が `n` で終わる

文字は1文字ずつ比べます（`kame` の次は `e` で始まる語。かなのしりとりとは違います）。

## 入力

```
w_1
w_2
...
w_m
```

- 各 `w_i` は英小文字のみからなる、長さ 2 以上 10 以下の文字列
- `1 <= m <= 20`

## 出力

最初に反則した語の番号（1始まり）。反則がなければ `0`。

## 入出力例

入力:

```
sakura
ame
eki
ika
ame
```

出力:

```
5
```

5語目の `ame` は2語目で既に出ています。

## ヒント

- `$.` には直前に読んだ行の行番号が入っています。
