# 06. 数字ヒストグラム

難易度: ★★☆

## 問題

数字の列が1行で与えられます。`0` から `9` がそれぞれ何回出てくるかを、縦の棒グラフで出力してください。

- グラフの高さ `H` は、最も多く出てくる数字の出現回数です。
- 上から `k` 行目（`k = 1..H`）の第 `d` 列（`d = 0..9`）は、数字 `d` の出現回数が `H - k + 1` 以上なら `#`、そうでなければ空白です。
- 最後の行に `0123456789` を出力します。

## 入力

```
s
```

- `s` は `0`〜`9` からなる、長さ 1 以上 100 以下の文字列

## 出力

`H + 1` 行のグラフ。行末の空白は判定上無視されます。

## 入出力例

入力:

```
31415926535
```

出力:

```
     #
 # # #
 ######  #
0123456789
```
