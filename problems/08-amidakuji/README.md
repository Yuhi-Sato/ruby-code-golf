# 08. あみだくじ

難易度: ★★☆

## 問題

あみだくじが与えられます。上にいる人がそれぞれ縦線をたどって下に着いたとき、下に並ぶ順番を出力してください。

1行目は上に並ぶ人の名前（英大文字1文字）を空白区切りで並べたものです。
2行目以降があみだくじの本体で、偶数番目の文字（0始まり）は縦線 `|`、奇数番目の文字は横線 `-` か空白です。
横線は左右の縦線をつなぎ、そこを通ると隣の縦線に移ります。

同じ行で横線が連続することはありません（`|-|-|` は出てきません）。

## 入力

```
c_1 c_2 ... c_n
row_1
...
row_h
```

- `2 <= n <= 10`, `1 <= h <= 15`
- 各行の末尾の空白は省かれていることがあります

## 出力

下に着いた順に名前を空白区切りで1行に出力します。

## 入出力例

入力:

```
A B C D
|-| |-|
| |-| |
|-| | |
```

出力:

```
D B A C
```

## ヒント

- 上の行から順に、横線のあるところで隣どうしを入れ替えていくだけです。
- `String#scan` のブロックの中では `$~` でマッチ位置がわかります。
