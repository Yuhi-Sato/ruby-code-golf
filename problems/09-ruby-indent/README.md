# 09. Ruby インデント整形

難易度: ★★★

## 問題

インデントがぐちゃぐちゃになった Ruby のコードが与えられます。各行の先頭と末尾の空白を取り除き、次のルールでインデントし直してください（1段 = 空白2個）。

現在の段数 `L` を0から始めて、各行 `s`（前後の空白を除いたもの）について順に処理します。

1. `s` が空なら空行を出力する
2. `s` が `end` `else` `elsif` `when` `rescue` `ensure` のいずれかの単語で始まるなら `L - 1` 段、そうでなければ `L` 段で `s` を出力する
3. `s` が `end` で始まるなら `L` を1減らす
4. `s` が `def` `class` `module` `if` `unless` `while` `until` `case` `begin` のいずれかの単語で始まる、または単語としての `do` か `do |...|` で終わるなら `L` を1増やす

「単語」とは、その語の前後が英数字やアンダースコアでないことです（`endpoint` は `end` で始まる語ではなく、`undo` や `todo` は `do` で終わる語ではありません）。

## 入力

Ruby のコード。

- 行数は 1 以上 40 以下
- 上のルールで正しく整形できるコードだけが与えられます（後置の `if` は行頭に来ない、`{ }` ブロックは1行で閉じる、など）

## 出力

整形したコード。

## 入出力例

入力:

```
def hi(xs)
xs.each do |x|
      if x
puts x
  else
puts 0
   end
end
end
```

出力:

```
def hi(xs)
  xs.each do |x|
    if x
      puts x
    else
      puts 0
    end
  end
end
```
