# 10. 罫線化

難易度: ★★★

## 問題

`#` と `.` からなる盤面が与えられます。`#` のマスを、上下左右に隣接する `#` とつながるような罫線文字に置き換えて出力してください。`.` のマスは空白にします。

上下左右の `#` の有無に応じて、次の文字を使います（盤面の外は `.` とみなします）。

| つながる方向 | 文字 | つながる方向 | 文字 |
| --- | --- | --- | --- |
| なし | `■` | 上下左 | `┤` |
| 上 / 下 / 上下 | `│` | 上下右 | `├` |
| 左 / 右 / 左右 | `─` | 左右下 | `┬` |
| 右下 | `┌` | 左右上 | `┴` |
| 左下 | `┐` | 上下左右 | `┼` |
| 右上 | `└` | | |
| 左上 | `┘` | | |

## 入力

```
row_1
...
row_h
```

- 各行は `#` と `.` のみからなり、すべて同じ長さ `w`
- `1 <= h, w <= 20`

## 出力

`h` 行の罫線図。行末の空白は判定上無視されます。

## 入出力例

入力:

```
#####
#.#.#
#####
.....
...#.
```

出力:

```
┌─┬─┐
│ │ │
└─┴─┘

   ■
```

## ヒント

- 上下左右を1, 2, 4, 8のビットにすると、16通りの文字を1本の文字列から引けます。
