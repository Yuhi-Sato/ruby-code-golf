# AB01. Split of Grapheme

出典: Anybatross YAPC::Hiroshima 2024 Hole 1（[元の問題](https://perlbatross.kayac.com/contest/2024hiroshima/challenge/1)）

## 問題

文字列が1行に1つずつ与えられます。各行を1文字目・3文字目・5文字目…をつなげた文字列と、2文字目・4文字目・6文字目…をつなげた文字列に分け、空白1つで区切って出力してください。

ここでの「1文字」は、見た目の1文字（書記素クラスタ）です。結合文字で書いた濁点つきの「か」＋「゛」や、合字の絵文字（👨‍👩‍👧）、国旗（🇯🇵）も、それぞれ1文字として数えます。

## 入力

- 1行以上。各行の文字数（書記素クラスタの数）は2以上の偶数です。
- 入力は UTF-8 で、改行で終わります。

## 出力

入力の各行について `<奇数番目の文字> <偶数番目の文字>` を1行ずつ出力します。

## 入出力例

入力:

```
rpuebryl
ふはくこおだかて
```

出力:

```
ruby perl
ふくおか はこだて
```
