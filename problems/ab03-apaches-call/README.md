# AB03. Apache's Call

出典: Anybatross YAPC::Hiroshima 2024 Hole 3（[元の問題](https://perlbatross.kayac.com/contest/2024hiroshima/challenge/3)）

## 問題

Apache の combined 形式のアクセスログに、処理時間（マイクロ秒）を末尾に足したものが与えられます。

```
%h %l %u %t "%r" %>s %b "%{Referer}i" "%{User-agent}i" %D
```

ログを1分ごとにまとめ、各分のステータスコードの件数を 2xx・3xx・4xx・5xx の順に空白区切りで出力してください。

ただし、ある分の 5xx が **10件を超えたら**、その分は出力せずに、そこで処理を打ち切ってください（それより後の分も出力しません）。

## 入力

- 1行以上のログ。行は時刻順に並んでいます。
- ログはすべて同じ日の同じ時（hour）の中に収まっています。
- ステータスコードは 200〜599 のどれかです。
- 1件もリクエストの無い分は、出力しません。

## 出力

リクエストのあった分ごとに、時刻順に `<2xx> <3xx> <4xx> <5xx>` を1行ずつ出力します。

## 入出力例

入力:

```
192.0.2.1 - - [21/Nov/2026:10:15:03 +0900] "GET / HTTP/1.1" 200 512 "-" "curl/8.4.0" 1200
192.0.2.7 - - [21/Nov/2026:10:15:40 +0900] "GET /old HTTP/1.1" 301 0 "-" "curl/8.4.0" 800
192.0.2.1 - - [21/Nov/2026:10:15:59 +0900] "POST /login HTTP/1.1" 403 128 "https://example.com/" "Mozilla/5.0" 5400
192.0.2.9 - - [21/Nov/2026:10:17:12 +0900] "GET /api HTTP/1.1" 503 64 "-" "Go-http-client/1.1" 30000
192.0.2.9 - - [21/Nov/2026:10:17:30 +0900] "GET /api HTTP/1.1" 200 2048 "-" "Go-http-client/1.1" 2500
```

出力:

```
1 1 1 0
1 0 0 1
```

## 元の問題との違い

元の問題文は「1分ごと」の区切り方や、打ち切る分を出力するかどうかがはっきりしません。
ここでは、実際に正解（AC）した参加者の記録に合わせて「時刻の分ごとにまとめる」「打ち切る分は出力しない」としています。
