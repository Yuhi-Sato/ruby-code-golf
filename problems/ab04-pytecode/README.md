# AB04. Pytecode

出典: Anybatross YAPC::Hiroshima 2024 Hole 4（[元の問題](https://perlbatross.kayac.com/contest/2024hiroshima/challenge/4)）

## 問題

スタック1本だけで動く小さな言語のインタプリタを書いてください。プログラムは1行に1トークンで与えられます。
下の命令以外のトークンは整数で、スタックに積みます。

| 命令 | 動作 |
| --- | --- |
| `+` `-` `*` `/` `%` | 上の値を `b`、その下の値を `a` として2つ取り出し、`a 演算 b` を積む |
| `=` `!=` `<` `>` `<=` `>=` | 同じく `a 比較 b` が成り立てば `1`、成り立たなければ `0` を積む |
| `dup` | 一番上の値を複製して積む |
| `drop` | 一番上の値を捨てる |
| `swap` | 上の2つを入れ替える |
| `.` | 一番上の値を取り出し、区切りなしで出力する |
| `cr` | 改行を出力する |
| `if` … `else` … `then` | 値を1つ取り出し、`1` なら `if`〜`else` の間を、`0` なら `else`〜`then` の間を実行する |
| `begin` … `until` | 間を実行してから値を1つ取り出し、`0` なら `begin` の直後に戻る。`1` なら抜ける |

## 入力

- 1行に1トークン。整数のトークンは 0 以上です（計算の途中で負の数になることはあります）。
- `/` は必ず割り切れ、`%` は `a` が 0 以上・`b` が正です。
- `if` と `until` が取り出す値は必ず `0` か `1` です。
- `if` の分岐の中に `if` は現れません。`begin` … `until` は入れ子になることがあります。
- スタックが空のときに値を取り出すことはありません。

## 出力

`.` と `cr` が出力したもの。

## 入出力例

入力:

```
3
4
+
.
cr
5
begin
dup
.
1
-
dup
0
=
until
drop
cr
```

出力:

```
7
54321
```

元の問題文は、演算の左右の順、`if` が値を取り除くかどうか、割り算の扱いなどがはっきりしません。
