# AB05. Portalbress Gramana

出典: Anybatross YAPC::Hakodate 2024 Hole 1（[元の問題](https://perlbatross.kayac.com/contest/2024hakodate/challenge/1)）

## 問題

各行に、空白1つで区切られた単語が並んでいます。その行の単語がすべて互いにアナグラム（同じ文字を同じ数ずつ使った並べ替え）になっていれば `1`、そうでなければ `0` を出力してください。

大文字と小文字は別の文字です（`Ruby` と `ruby` はアナグラムではありません）。

## 入力

- 1行以上。各行は2個以上の単語からなります。
- 単語は英数字・ひらがな・全角カタカナ（`ー` を含む）でできています。
- 入力は UTF-8 で、改行で終わります。

## 出力

各行について `1` か `0` を1行ずつ出力します。

## 入出力例

入力:

```
listen silent enlist
ruby Ruby
いるか かるい
```

出力:

```
1
0
1
```
