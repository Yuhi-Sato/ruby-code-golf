# AB06. QuAArterPix

出典: Anybatross YAPC::Hakodate 2024 Hole 2（[元の問題](https://perlbatross.kayac.com/contest/2024hakodate/challenge/2)）

## 問題

`` ` ``（バッククォート）と `#` だけでできた絵が与えられます。これを縦横それぞれ半分（面積で 1/4）に縮小してください。

絵を重ならない 2×2 のブロックに分け、各ブロックを1文字にします。ブロックの4文字のうち多いほうの記号を使い、2対2の同数のときはブロックの左上の記号を使います。

## 入力

- 絵の高さと幅はどちらも 2 以上の偶数で、すべての行の長さは同じです。
- 幅と高さは 40 以下です。

## 出力

縮小した絵。

## 入出力例

入力:

```
``##
`###
#`#`
``#`
```

出力:

```
`#
`#
```

左下のブロック（`` #` `` と ` `` `）は `#` が1つなので `` ` ``、右下のブロック（`` #` `` と `` #` ``）は2対2の同数なので左上の `#` になります。
