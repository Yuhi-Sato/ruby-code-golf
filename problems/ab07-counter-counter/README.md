# AB07. Counter Counter

出典: Anybatross YAPC::Fukuoka 2025 Hole 1（[元の問題](https://perlbatross.kayac.com/contest/2025fukuoka/challenge/1)）

## 問題

`A` や `B` のような文字の中にある閉じた空間を「カウンター」と呼びます。各行に含まれるカウンターの数を数え、`<それまでの累計>,<その行の数>` の形で出力してください。

数字と英大文字のカウンターの数は次のとおりです。ここに無い文字（記号や空白を含む）は 0 として数えます。

| 文字 | カウンター |
| --- | --- |
| `0` `4` `6` `9` `A` `D` `O` `P` `Q` `R` | 1 |
| `8` `B` | 2 |

`@` や `&` のように見た目に閉じた空間のある記号も、数えません。

## 入力

- 1行以上。各行は数字・英大文字・記号・空白からなる、1文字以上の文字列です。英小文字は現れません。

## 出力

各行について `<累計>,<その行の数>` を1行ずつ出力します。

## 入出力例

入力:

```
RUBY KAIGI
8 BALL
C-3PO
```

出力:

```
4,4
9,5
11,2
```
