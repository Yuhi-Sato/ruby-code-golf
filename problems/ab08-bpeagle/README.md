# AB08. BPEagle

出典: Anybatross YAPC::Fukuoka 2025 Hole 2（[元の問題](https://perlbatross.kayac.com/contest/2025fukuoka/challenge/2)）

## 問題

英小文字の単語を空白1つで区切った文章が1行で与えられます。次の手順（BPE: バイトペア符号化）で文章を圧縮してください。

1. 各単語の中で隣り合う2文字の組をすべて数えます。単語をまたぐ組は数えません。
2. 最も多く現れる組を選び、文章中のその組をすべて新しい記号に置き換えます。記号は `A`、`B`、`C`… の順に使います。
   最も多い組が複数あるときは、文章の中で先に現れるものを選びます。
3. 置き換えた後の文章で 1 に戻り、最も多い組の出現回数が1回になったら終わります。置き換えた記号も1文字として組に含めます。

## 入力

- 英小文字の単語を空白1つで区切った1行。少なくとも1回は置き換えが起こります。
- 置き換えは 26 回以内に終わります。
- `aaa` の中の `aa` を何回と数えるかで答えが変わるような入力は現れません。

## 出力

- 1行目: 置き換えの記録を `<記号>:<組>` の形で、使った順にカンマ区切りで並べたもの。
- 2行目: 圧縮後の文章（単語は空白1つで区切る）。

## 入出力例

入力:

```
banana bandana cabana
```

出力:

```
A:an,B:bA,C:Aa
BC BdC caBa
```

1回目は `an`（5回）を `A` に、2回目は同数の `bA` と `Aa` のうち先に現れる `bA` を `B` に、3回目は `Aa` を `C` に置き換えます。
